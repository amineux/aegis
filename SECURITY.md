# Security Policy

Osiris Command is a personal OSINT and situational-awareness dashboard. The same
capabilities that make it useful can be misused.

**By using this software, you agree to the following:**

1. **Defensive / authorized use only.** Use the tools for defensive, educational,
   and authorized monitoring.
2. **Authorized targets.** Do not scan, probe, or interact with infrastructure
   you do not own or lack explicit permission to test.
3. **Follow the law.** You are responsible for complying with applicable local,
   national, and international law.
4. **No offensive use.** Do not use this software for unauthorized access,
   harvesting, or attack operations.

The authors and contributors are not responsible for misuse.

## Reporting a vulnerability

If you find a security issue in **this** repository (`amineux/osiris-command`):

1. Open a private report or an issue on
   [github.com/amineux/osiris-command](https://github.com/amineux/osiris-command/issues)
   if a private channel is not available.
2. Include impact and enough detail to reproduce.
3. Do not disclose the issue publicly until it has been addressed.
